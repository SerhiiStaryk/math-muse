# 📱 Тестування на мобільних пристроях

## Швидкий старт

### 1. Запуск dev сервера для мобільних пристроїв

```bash
npm run dev:mobile
```

Це запустить Vite dev сервер, доступний з будь-якого пристрою у вашій локальній мережі.

### 2. Знайдіть IP-адресу вашого комп'ютера

**Windows:**
```bash
ipconfig
```
Шукайте `IPv4 Address` (наприклад: `192.168.1.100`)

**macOS/Linux:**
```bash
ifconfig | grep "inet "
```

### 3. Відкрийте на мобільному пристрої

На вашому телефоні/планшеті відкрийте браузер і перейдіть за адресою:
```
http://[YOUR_IP]:5173
```

Наприклад: `http://192.168.1.100:5173`

## Доступні скрипти

### `npm run dev:mobile`
Запускає dev сервер з доступом з локальної мережі.

### `npm run dev:mobile:debug`
Те саме, але з детальним логуванням для діагностики проблем.

### `npm run preview:mobile`
Запускає production build для тестування на мобільних пристроях.

## Тестування різних viewport'ів

### У Chrome DevTools:
1. Натисніть `F12`
2. Натисніть `Ctrl+Shift+M` (Toggle Device Toolbar)
3. Виберіть пристрій:
   - **iPhone SE** (375×667) - мінімальний розмір
   - **iPhone 12 Pro** (390×844)
   - **Pixel 5** (393×851)
   - **iPad Mini** (768×1024)

### Кастомні розміри для тестування:
- **320px** - iPhone SE (старий)
- **375px** - iPhone 6/7/8
- **390px** - iPhone 12/13/14
- **414px** - iPhone Plus
- **768px** - iPad Portrait
- **1024px** - iPad Landscape

## Перевірка горизонтального скролу

### Метод 1: Візуальна перевірка
1. Відкрийте DevTools
2. Встановіть viewport на 320px
3. Прокрутіть сторінку вправо/вліво
4. Якщо є скрол - є проблема

### Метод 2: JavaScript в консолі
```javascript
// Перевірка чи є горизонтальний overflow
document.body.scrollWidth > window.innerWidth
// true = є проблема, false = все ОК
```

### Метод 3: CSS Debug
Додайте тимчасово в DevTools:
```css
* {
  outline: 1px solid red !important;
}
```
Елемент, що виходить за межі, буде видно.

## Поради для тестування

### ✅ Що перевіряти:
- [ ] Немає горизонтального скролу на 320px
- [ ] Всі кнопки натискаються (мінімум 44×44px)
- [ ] Текст читабельний (мінімум 16px)
- [ ] Елементи не перекриваються
- [ ] Форми зручно заповнювати
- [ ] Анімації не лагають

### ⚠️ Типові проблеми:
- Фіксовані ширини (`width: 500px`)
- Використання `100vw` (створює скрол через scrollbar)
- Великі padding/margin
- Grid/Flex без `flexWrap: 'wrap'`
- Таблиці без `overflow-x: auto`

## Troubleshooting

### Не можу підключитися з телефону
1. Переконайтеся, що телефон і комп'ютер в одній Wi-Fi мережі
2. Вимкніть firewall на комп'ютері (тимчасово)
3. Спробуйте інший браузер на телефоні

### Сторінка не оновлюється автоматично
1. Перезапустіть `npm run dev:mobile`
2. Очистіть кеш браузера на телефоні
3. Використайте режим інкогніто

### Повільна робота
1. Використайте `npm run build` + `npm run preview:mobile`
2. Перевірте Network throttling в DevTools
3. Тестуйте на реальному пристрої, а не емуляторі
